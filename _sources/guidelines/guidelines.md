# Workflow and guidelines

The full ACT workflow includes the following steps:

1. Download the cell files or otherwise set up the simulation directory.
2. (Optional) Convert the activation functions of interest to the  Boltzmann ($V_{1/2}$, $k$) format.
3. (Optional) Estimate passive properties.
4. (Optional) Segment the cell.
5. Optimize the soma conductances.

Note that steps 2-5 are independent and one does not have to execute each of them one. For example, if the passive properties for the cell are known, step 3 can be skipped.
